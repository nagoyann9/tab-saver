# タブをブックマークして閉じる

開いているタブをすべてブックマークに保存してから、まとめて閉じる Chrome 拡張機能です。
ブラウザのタブが散らかったときに、ワンクリックで「保存して片付ける」ことができます。

## 特長

- 現在のウィンドウで開いている http/https のタブをすべてブックマークに保存
- 保存後、タブを閉じてウィンドウを片付ける（空のタブを1つ残します）
- 日付フォルダ（例: `260602Tue2032`）にまとめるオプション付き
- **外部との通信を一切行いません。** 取得したURL・タイトルは端末内でブックマークに保存するだけで、外部に送信しません。

## 権限について

この拡張機能は次の2つの権限のみを使用します。

| 権限 | 用途 |
| --- | --- |
| `tabs` | 開いているタブのURLとタイトルを取得してブックマークに保存するため |
| `bookmarks` | ブックマークおよびフォルダを作成するため |

`tabs` 権限はインストール時に「閲覧履歴の読み取り」という趣旨の警告が表示されますが、これは全タブのURLを取得するために必要なものです。取得した情報を外部へ送信することはありません。コンテンツスクリプトや特定サイトへのアクセス権限（host permissions）は使用していません。

## インストール方法（開発者モード）

1. このリポジトリをダウンロードまたは clone する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. `manifest.json` が直接入っているフォルダを選択する

## 使い方

ツールバーの拡張機能アイコンをクリックし、「すべて保存して閉じる」を押します。
「日付フォルダにまとめる」のチェックを外すと、ブックマークバー直下に直接保存します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `popup.html` | ポップアップのUI |
| `popup.js` | 保存とタブを閉じる処理 |
